Welcome, Buddy

Geo Studio is a single-file, fully-offline geomatics tool. It turns simple spreadsheets into professional Google-Earth KMZ maps — borehole core-log cards, boundary pillars, cadastral plot cards, offset / safety-belt polygons — and converts between CSV, Excel, KML, KMZ, DXF, GeoJSON, GPX, WKT and Shapefile. Everything runs inside Edge — nothing is uploaded, nothing is installed.

Ore rule applied everywhere: a core interval is ORE only when Al2O3 ≥ 30 and SiO2 ≤ 7 and TAA is not 0/blank. A borehole is POSITIVE if it has at least one ore interval.

Step 1 — Download a template

Each template already contains realistic sample rows so you can see the exact format, then replace with your data. THIS IS SAMPLE DATA

Step 2 — Open the matching app & drop your file

Borehole Mapper → borehole CSV (+ optional pillar CSV) Cadastral Mapper → plot geometry + land-record CSV Boundary Offset → boundary CSV / KML / KMZ / GeoJSON Format Converter → any file → any format

Use the app launcher (top-left) to switch apps. Then click Generate and download your file — double-click a KMZ to open it in Google Earth Pro.

1Borehole Mapper MULTI-MINE

Works for any mine. Pick or build a Mine Profile (grade columns + cutoff rule + card colours), drop your borehole CSV, and generate rich core-log KMZ cards. Profiles are saved locally on this device.

1Cadastral Builder

Give it 2 files: (1) plot geometry - CSV vertices, KML, or KMZ - where each polygon is named by its Plot No; and (2) a land-record CSV keyed by Plot. It merges them into a KMZ where every plot polygon carries a full cadastral card and its computed area. Templates: cad_geometry & cad_land.

1Offset & Gap-Fill

Offset a boundary inward or outward by metres, or build a gap-fill belt (the ring between original and offset - your safety-belt use-case). The offset is miter-capped: sharp corners are cleanly beveled, so it never spikes. Input CSV / KML / KMZ; output KML, KMZ or CSV. Template: ml_boundary.
